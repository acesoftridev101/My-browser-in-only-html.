# My-browser-in-only-html.
This is a browser that opens in a bigger browser. I made this just for fun and this is made only in html. What I like about it is that it can open up websites without iframes. If it has an iframe it won't load since this browser doesn't support iframes. For example, if you go on roblox.com it won't load because it has an iframe. There's no .gitignore since there's no .gitignore for html. Don't mind the file size. It is 4.18 kb for only the tlmfa.html file because this is just a small browser. It has all the stuff it needs since it opens in another browser. When you boot the browser up it asks for a password. The password is access.
